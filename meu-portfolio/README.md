# Josué Veloso - Portfólio

Meu portfólio pessoal e currículo web construído com Vue 3, Vite e Tailwind CSS.

## Stack
- Vue 3 (Composition API)
- Tailwind CSS v3
- Vite

## Como rodar localmente

```bash
# Instalar dependências
npm install

# Rodar servidor de desenvolvimento
npm run dev
```

## Estrutura do Projeto
- `/src/components` - Componentes da interface.
- `/src/data` - Arquivo com os dados (experiências, projetos) injetados nos componentes.
- `/src/composables` - Lógica de animação de scroll via Intersection Observer.
